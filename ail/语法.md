mode为设置模式，如果代码最后还有个mode xx（mode就是命名空间，以这个为准），如：

```ail
mode train
print()

mode running
```

就代表从mode train到mode running的代码块为训练代码train，如果是最后一块，就到末尾，mode以前的代码算无效代码
参数：train训练模式
running 运行模式
xxx 其他自定义名称
如果模式重复冲突，就算报错
整体类似命名空间
---------分割线--------

```ail
X : int xxx 1
@xxxxx()
X : def i(xxxx):
    xxx
```

三个点：
1: X 这个是类名，如果一个函数或变量和其他什么什么东西，的前面有字母加冒号（空格不敏感），如:

```ail
TEST: def i():   //不强制大写，只要加了:就行
    xxx
```

想要调用i函数就需要这样写，TEST.i()，变量也是一样，同类共享变量，如果需要实例化，就这样：

```ail
TEST: string test xxx
i=TEST.init()   //返回独立副本
i.test = xxx   //新建一个隔离类，就相当于new class类一样
```

2，变量int xxx 1 代表一个int变量，名xxx，等于1，变量结构 ：类名(可选) 类型(可选) 名称 值
，如：X: int test 10
3，@xxxxx，这个挺重要的，代表着当函数可以不填参数，直接使用最近的xxxxx()函数返回的值作参数，如果是@xxxxx@，那么就还会把参数传到下一个最近的xxxxx()函数，如果没有才需要填参数，如：

```ail
@x@
def d(x):
    return x+1
def x(num):
    return num+1
x(1)
print()
d()     //此时d()使用上方x()的返回值
x()     //使用上方d()的返回值

```

--------分割线--------
训练相关代码语法

```ail
@layer xx   //只能有一个，layer不可嵌套，一个神经网络层嵌套干什么
layer{
50,60
60,30
30,50
}
```

这个是定义训练层的代码使用花括号括起来
@layer为layer的特殊语法，代表整个layer块的名称为xx，后面训练时要用到
定义层有两种方式一种用layer花括号包裹，然后调用，如:

```ail
X: train echo = 100     // train代表变量为训练变量，一种特殊类型，直接传入nn训练函数
X: train lr = 0.01
X: string save_path = xxx
&layer xx
layer{       //层定义，默认最上面是输入，最下面是输出，中间是隐藏
50,60
60,30
30,50
}
&train_main    //特殊语法，代表下面这个函数为训练主代码
def train(X):    //传入X类里面的训练参数（没的话就用默认），如果有echo （如果echo为0或未定义，就使用默认参数），那么就重复执行这个函数，只传入train类型的变量，即本函数无需X.lr使用lr变量，而是可以直接调用lr变量
    train.nn_layer(xx)     //传入的xx为layer xx下面的那个神经网络层，nn_layer要传训练层
    ReLU_layer()     //内置函数，带有@train.nn_layer
    &train_finish     //训练完成后执行下面的，因为要优先执行训练，然后是运行，所以要先保存，防止被其他优先级更高的函数抢了
    save(X.save_path) //保存模型到xxx路径
```

和另一个代码一段一段的训练，例：

```ail
&train_main
def train():
    train.nn(20,80)
    ReLU()
    train.nn(80,60)
```
